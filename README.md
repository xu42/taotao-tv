# 桃桃TV · 精简版

专为电视、投影等大屏设备设计的第三方浏览器应用。精简版只做一件事：**看电视直播**。

> 设计宗旨：**简化、美化、易于操作使用**。

---

## 界面

应用只有一个页面——直播页，打开即播：

- 每次启动都从 **CCTV-1** 开始（**不记忆**上次频道，不写任何观看记录）

按 MENU / SETTINGS / OK 呼出**二级分类菜单**，左栏选分类（央视 / 卫视 / 各省），右栏选频道。
菜单只占屏幕**左半边**，右半边完全留白——直播画面照常可见，点这块留白即可收起菜单。

遥控器按**左 / 右**在「分类栏」与「频道栏」之间移动焦点，
**没有焦点的那一栏会自动压暗（约 40% 不透明）**，一眼就能看出当前操作的是哪一栏。

按**返回**，屏幕中下方会浮出提示「再按一次「返回」键退出应用」，
**1.2 秒内再按一次返回**即直接退出应用；不按的话提示 2.4 秒后自动淡出。

### 平板触屏

| 操作 | 作用 |
| --- | --- |
| 点**左半屏** | 拉出切台菜单 |
| 点**右半屏** | 等同于按一次返回键（1.2 秒内连点两次 = 退出应用） |
| 点菜单右侧那块留白 | 收起切台菜单 |
| 点分类 / 频道 | 切分类 / 播放该频道并收起菜单 |

### 遥控器操作

**直播 · 播放中**

| 按键 | 作用 |
| --- | --- |
| 上 / 下 | 上一个 / 下一个频道（在当前分类内循环） |
| 左 / 右 | 切换这个台的下一个 / 上一个**播放源** |
| OK / MENU / SETTINGS | 打开切台菜单 |
| 返回 | 浮出退出提示；**1.2 秒内再按一次 = 直接退出应用** |

**直播 · 切台菜单**（二级分类）

| 按键 | 作用 |
| --- | --- |
| 上 / 下 | 在本栏内移动（左栏选分类，右栏选频道） |
| 左 / 右 | 在「分类栏」与「频道栏」之间移动焦点（另一栏会压暗） |
| OK | 在左栏 = 进入该分类（焦点跳到右栏）；在右栏 = 播放该频道并收起菜单 |
| MENU / SETTINGS | 收起菜单 |
| 返回 | 收起菜单 |

## 与上游版本的主要差异

1. **彻底移除第三方浏览器内核** — 不再下载、不再打包任何内核文件，统一使用设备自带的系统 WebView。因此启动更快、安装包更小、也不需要额外的内核权限与后台服务。
2. **只保留直播模块** — 影视（点播）模块及其全部代码、页面、适配源已整体删除，应用首页就是直播页。
3. **完全本地化，零远端依赖** — 不再有任何自建服务端：没有配置拉取、没有网页资源热更新、没有崩溃上报、没有应用自升级。所有频道数据与网页资源都打包在 APK 内，离线也能用。
4. **直播切台菜单重做成二级分类** — 左栏是分类（央视 / 卫视 / 各省），右栏是该分类下的频道；不再需要在列表里挑「播放源」。
5. **一个台可以有多个源** — 同一个频道的多路源被合并成一条记录，默认优先央视网；某一路播不出来时自动切到下一路，也可以播放中按左右键手动切换。
6. **直播切台加载体验** — 切换频道时先显示跳动圆点遮罩，等真实画面就绪后再淡出，不再露出未渲染完成的网页。
7. **移除百视通片源** — 该源长期没有可用内容，已连同其页面与适配代码一并删除。
8. **移除依赖服务端代理的四川频道** — 这批频道原本要靠服务端 `/channel/proxy` 转发，随「零远端依赖」一并删除；四川卫视仍可通过「央视频」源在卫视分组收看。
9. **清理上游遗留文件** — 删除开发辅助目录与一批已不可达的旧页面 / 脚本，内置网页资源大幅瘦身。
10. **版本号按编译时间生成** — 不再手工维护；release 包开启 R8 与资源压缩，安装包明显变小。
11. **应用内不再包含推广与版权声明内容**；仓库 `LICENSE`（Apache 2.0）保持原样。
12. **不再有收藏、观看历史与本地数据库** — 收藏功能整体删除，启动固定播 CCTV-1、不记录上次频道；原本用 SQLite（Room）承载的这块依赖已连同数据库、建表与混淆规则一起移除，应用不再创建任何本地数据库。
13. **退出交互极简** — 没有设置面板、没有弹窗、没有二级菜单：按一次返回浮出提示，再按一次直接退出。
14. **切台菜单两栏有明确焦点区分** — 焦点所在的栏正常亮度，另一栏压暗，遥控器按左右键时能立刻看出焦点在分类还是频道。

## 编译

### 环境要求

- JDK 17
- Android SDK Platform 34 / Build Tools 34
- Node.js（构建内置网页资源用）

### 步骤

```bash
# 1. 生成内置网页资源（assets 不入库，必须先执行）
node scripts/build-web.js

# 2. 指定 Android SDK 路径
echo "sdk.dir=$HOME/Library/Android/sdk" > android/local.properties

# 3. 编译（单个通用包）
cd android
./gradlew assembleRelease
```

产物：`android/app/build/outputs/apk/release/taotao-tv-<versionName>.apk`

- `versionName` 默认取编译时刻（`yyyyMMdd.HHmm`），`versionCode` 取 `yyMMddHH`，都是自动递增的，不用再手工维护。
  需要复现某次构建时可以覆盖：`./gradlew assembleRelease -PbuildTime=2026-09-18T16:30`。
- 固定产出**一个通用包**，不做 ABI 拆分。
- 未配置签名密钥时会自动回退到 debug 签名，产物依然可以直接安装，便于本地与 CI 使用。
  配置正式签名只需在 `android/local.properties` 写入 `RELEASE_STORE_FILE` / `RELEASE_STORE_PASSWORD` / `RELEASE_KEY_ALIAS` / `RELEASE_KEY_PASSWORD`。

推送 tag（`v*`）时 GitHub Actions 会自动编译并把 APK 发布到对应 Release，详见 `.github/workflows/build-apk.yml`。

## 数据来源

客户端**不访问任何远程接口**，全部数据来自 APK 内置资源：

- 频道数据：`web/tv-web/js/cctv/tv.json`（构建时由 `tv.yml` 生成），原生 `UpdateService` 与网页侧都读它。
- 播放页面与脚本：`web/tv-web/`，通过「伪源」`https://tv.xu42.com/tv-web/` 由 `WebViewClientImpl.shouldInterceptRequest` 从 APK 的 `assets/` 读取，**不部署、不走网络**。
- 播放源本身（央视网 / 央视频等公开流地址）由网页在其 iframe 内直接播放；唯一由原生侧兜底的跨域请求走 JS Bridge。

## 开发提示

- 所有地址常量的**唯一出处**是 `android/app/src/main/java/com/xu42/tv/live/util/AppConfig.java`（当前只剩 `WEB_ORIGIN`）。
- 内置网页使用「伪源」`https://tv.xu42.com/tv-web/`，由 `WebViewClientImpl.shouldInterceptRequest` 从本地读取，**不需要真实部署、也不会产生网络请求**。修改它需同步改 `AppConfig.WEB_ORIGIN` 与 `web/tv-web/js/end.js` 的 `_tvWebOrigin`。
- 频道数据 `web/tv-web/js/cctv/tv.yml` 里同一个台可能出现在多个分组。运行时由 `UpdateService.initTvData()` 按频道名合并成一条并建立「任一源地址 → 频道」的索引，界面上只展示频道。
- 改动 `web/tv-web` 后务必重新执行 `node scripts/build-web.js`，否则 App 里看到的还是旧页面。
